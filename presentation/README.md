# Презентация: реализация и сравнение алгоритмов проверки изоморфизма гиперграфов отношений

Сделана на основе шаблона
[spbu-se/report_presentation_template](https://github.com/spbu-se/report_presentation_template)
(тема beamer `SPbGU`, формат 16:9).

## Сборка

```sh
make          # LuaLaTeX → presentation.pdf
make data     # обновить data/ из ../report/data (после нового прогона compare.py и сборки отчёта)
```

Числа и данные графиков берутся из `../report/data`, которые строит `../report/data/prepare.py`
по результатам `../compare.py`; `make` копирует нужные файлы в `data/`, если они изменились.
По умолчанию используется LuaLaTeX: он находит шрифты CMU в дереве TeX Live.
Для XeLaTeX (`make ENGINE=xelatex`) шрифты должны быть установлены в систему
(`sudo apt install fonts-cmu`). Для показа на проекторе 4:3 уберите опцию
`aspectratio=169` в `presentation.tex`.
