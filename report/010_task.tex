\section{Постановка задачи}
\label{sec:task}

Целью работы является реализация на языках Python и \Cpp{} алгоритмов проверки изоморфизма гиперграфов отношений из статьи Т.~М.~Косовской~\cite{KosovskayaIsom} и экспериментальное сравнение этих реализаций.
Для её выполнения были поставлены следующие задачи:
\begin{enumerate}
    \item разобрать алгоритмы \ISOMone{} и \ISOMn{} (раздел~\ref{sec:review});
    \item реализовать алгоритмы на Python (раздел~\ref{subsec:python});
    \item реализовать алгоритмы на \Cpp{} так, чтобы реализация выполняла тот же поиск, что и реализация на Python (раздел~\ref{subsec:cpp});
    \item разработать наборы тестовых задач и средства автоматического сравнения реализаций (раздел~\ref{subsec:compare});
    \item проверить корректность реализаций и сравнить их время работы (раздел~\ref{sec:experiment}).
\end{enumerate}
