# Изоморфизм гиперграфов отношений: реализации на Python и C++

Реализация алгоритмов проверки изоморфизма гиперграфов отношений ISOM-1 и ISOM-n
из статьи Т. М. Косовской «On the isomorphism of hypergraphs of relations»
на Python и C++, экспериментальное сравнение реализаций и отчёт о работе.

Обе реализации строят одинаковые деревья поиска: совпадают ответы, найденные
изоморфизмы, статистика поиска и пошаговые журналы. На 454 задачах выполнено
3095 проверок без расхождений; реализация на C++ быстрее в 56–144 раза,
в среднем в 84 раза. Подробности — в отчёте [`report/report.pdf`](report/report.pdf).

## Состав

| Файл | Содержание |
|---|---|
| `hypergraph_isomorphism.py` | реализация на Python: характеристики, структурное отображение, ISOM-1, ISOM⁻-1, MAP, BESTMAP, CONSISTENCY, REDUCTION, ISOM-n, полный перебор; примеры статьи и самопроверка |
| `hypergraph_isomorphism.cpp` | реализация на C++17 с тем же порядком обхода и тем же журналом поиска |
| `compare.py` | генерация наборов задач, запуск обеих реализаций, сверка результатов, замеры времени |
| `examples.txt` | примеры из статьи во входном формате |
| `bench/` | задачи (`cases_*.txt`) и результаты последнего прогона (`results.csv`, `samples.json`, `full_run.log`) |
| `report/` | отчёт в LaTeX (`report.pdf` — собранная версия) |

## Запуск

Нужны Python 3 без сторонних пакетов (проверено на 3.14) и g++ с поддержкой C++17 (проверено на g++ 15).

```sh
# Python: разбор примеров статьи и самопроверка с полным перебором
python3 hypergraph_isomorphism.py

# C++: сборка и запуск на примерах с подробным журналом поиска
g++ -O2 -std=c++17 -o hypergraph_isomorphism hypergraph_isomorphism.cpp
./hypergraph_isomorphism -v examples.txt

# сравнение реализаций (C++ собирается автоматически)
python3 compare.py --quick      # уменьшенные наборы
python3 compare.py              # полный прогон, около 13 минут при 1,6 ГГц
python3 compare.py --cases my.txt
```

Замеры времени выполняются по методике [spbu-se/measurements](https://github.com/spbu-se/measurements):
прогревочный запуск, 40 замеров на задачу, среднее и стандартное отклонение,
стандартное отклонение должно быть меньше 10 % среднего. Для воспроизводимых
результатов частоту процессора стоит зафиксировать, а процесс закрепить за одним ядром:

```sh
sudo cpupower frequency-set -g performance -d 1.6GHz -u 1.6GHz
echo 1 | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo
taskset -c 3 python3 compare.py
```

Отчёт собирается LuaLaTeX (TeX Live), таблицы и графики строятся из `bench/`:

```sh
cd report && make
```

## Формат задач

```
case <имя>
pred <имя> <арность> <n|c>     # n — рёбра-кортежи (тип 1), c — рёбра-множества (тип 2)
g1 <предикат> <вершина> ...    # ребро G1
g2 <предикат> <вершина> ...    # ребро G2; из G2 строится шаблон H
end
```

Обе реализации ищут все унификаторы λ, для которых Hλ = G1, и печатают их как
изоморфизмы G2 → G1.
